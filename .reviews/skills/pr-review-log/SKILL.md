# pr-review-log

Reusable review + logging skill. Portable: this lives under `.reviews/skills/`
so it does not depend on the generated `.cursor/` index. To activate it in a
repo, copy this folder to `.cursor/skills/pr-review-log/` and regenerate the
index (`python3 scripts/generate_cursor_index.py`) — see the README below.

## Procedure

1. **Understand the PR.** Read the diff and the changed files at the head commit.
   Do not trust the PR description's framing of the root cause.
2. **Find the real bug.** Prefer CI signal over prose: check failing checks and
   their logs. A red test usually names the exact cause.
3. **Fix the root cause.**
   - If a code change broke a test that asserts old behavior, update the test to
     assert the new intended behavior (mirror the existing pattern in that file).
   - Fix causes, not symptoms. Keep edits minimal and match surrounding style.
4. **Sweep related staleness.** Stale comments, mirrored constants, sibling
   workflows — fix the whole class, not just the one instance.
5. **Do not break generated/asserted artifacts.**
   - `.github/workflows/*.yml` is asserted as plain text by
     `tests/test_ci_workflow_changes.py`. Grep it before/after editing workflows.
   - `.cursor/INDEX.md` + `.cursor/skills/.index.yaml` are generated by
     `scripts/generate_cursor_index.py`; never hand-edit. Adding a `.cursor`
     skill requires regeneration or `scripts/check_cursor_artifacts.sh` fails.
6. **Write the records** under `.reviews/`:
   - `pr-<n>-review.md` — findings, fixes, out-of-scope, verification.
   - `continual-learning.md` — durable lessons (append, newest first).
   - `sessions/YYYY-MM-DD-<slug>.md` — what was done, gotchas, follow-ups.
7. **State verification.** Give the exact command to confirm green; never claim
   "passes" without running it.

## Return contract

- Summary of root cause + each fix, with full-path `path:line` citations.
- Explicit list of what was left out of scope and why.
- The verify command(s).

## Config

Honor `.reviews/agent-config.yaml` (eager, terse, code-mode; guardrails).
